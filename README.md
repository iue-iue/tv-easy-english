# やさしい英語字幕

テレビの日本語音声を聞き取り、やさしい英語（Plain English）の字幕にしてタブレットに表示するWebアプリです。

HTML・CSS・JavaScriptだけで出来ていて、変換作業（ビルド）や自前のサーバーはありません。ファイルを書き換えれば、そのまま反映されます。

## いまの状態

| フェーズ | 内容 | 状態 |
| --- | --- | --- |
| 0 | 音の入り口の確認 | タブレット実機で確認済み（内蔵マイク） |
| 1 | 最小の字幕（音声認識と翻訳をつなぐ） | 作成済み。本物のAPIキーとタブレット実機での確認待ち |
| 2 | 翻訳エンジンの比較 | これから |
| 3 | 音声認識エンジンの比較 | これから |
| 4 | 仕上げ（ホーム画面への追加、用語集、利用量の表示） | これから |

## 仕組み

1. マイクでテレビの音を拾い、16kHz・モノラル・16bitの音声データにする。
2. 音声認識エンジン（Soniox）へ送り、日本語の文字と、英語の速報訳を受け取る。
3. 日本語を文の切れ目で区切り、速報訳を灰色で表示する。
4. 翻訳エンジン（Claude）が、選んだ英語レベルに合わせた確定訳を返したら、それに置き換える。
5. 確定訳が3秒以内に届かない、または失敗したときは、速報訳をそのまま確定として先へ進む。

| `css/style.css` | 共通の見た目（ボタン、入力欄など） |
| `css/app.css` | 字幕画面の見た目（字幕の色、大きさ、設定の引き出し） |
| `js/app.js` | 字幕画面のボタンと表示の動き |
| `js/pipeline.js` | 字幕づくりの中心（文の区切り、確定訳の依頼、時間切れの扱い） |
| `js/subtitle-view.js` | 字幕を画面に描く（位置が変わるときは、なめらかに動かす） |
| `js/fonts.js` | 英語の字体の一覧と読み込み（字体を足すときはここに追加） |

| `js/stt/soniox.js` | 音声認識エンジン Soniox との接続 |
| `js/stt/index.js` | 音声認識エンジンの一覧（エンジンを足すときはここに追加） |
| `js/translate/claude.js` | 翻訳エンジン Claude との接続 |
| `js/translate/index.js` | 翻訳エンジンの一覧（エンジンを足すときはここに追加） |
| `js/translate/prompt.js` | 指示文を読み込み、翻訳エンジンへ渡す文章を組み立てる |

| `js/meter.js` | レベルメーター（音の大きさの棒） |

## 外部から読み込むもの

- Claudeの公式ライブラリ（`@anthropic-ai/sdk` 1.12.0）を、配信サービス jsDelivr から読み込みます。版は `js/translate/claude.js` の先頭で固定しています。
- 英語の字体を「標準」以外にした場合だけ、その字体を Google Fonts から読み込みます。

## パソコンで開いて確かめる

マイクは `https://` か `localhost` のページでしか使えません。ファイルをダブルクリックして開いても動かないので、このフォルダで次を実行し、Chromeで `http://localhost:8765/` を開きます。

```
python -m http.server 8765 --bind 127.0.0.1
```

## 守っていること

- APIキーは、ファイルにもリポジトリ（GitHub上の保管場所）にも書かない。設定画面で入力し、タブレットのブラウザの中だけに保存する。
- テレビの音声は保存しない。例外は、利用者が自分で操作して録る比較用の短い録音だけで、これもタブレットの中にとどめる。

## 更新が反映される仕組み

`sw.js` が、アプリのファイルを読み込むたびに「新しい版が出ていないか」をサーバーに確認させます。これがないと、ブラウザが古いファイルを最長10分使い続け、更新の直後に新旧のファイルが混ざってボタンが動かなくなることがあります。
