# やさしい英語字幕

テレビの日本語音声を聞き取り、やさしい英語（Plain English）の字幕にしてタブレットに表示するWebアプリです。

HTML・CSS・JavaScriptだけで出来ていて、変換作業（ビルド）や自前のサーバーはありません。ファイルを書き換えれば、そのまま反映されます。

## いまの状態

フェーズ0（音の入り口の確認）まで。字幕の画面はフェーズ1で `index.html` に入ります。

| フェーズ | 内容 | 状態 |
| --- | --- | --- |
| 0 | 音の入り口の確認 | 作成済み。タブレット実機での確認待ち |
| 1 | 最小の字幕（音声認識と翻訳をつなぐ） | これから |
| 2 | 翻訳エンジンの比較 | これから |
| 3 | 音声認識エンジンの比較 | これから |
| 4 | 仕上げ（ホーム画面への追加、用語集、利用量の表示） | これから |

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | ホーム。フェーズ1で字幕の画面になる |
| `check.html` | 音の入り口の確認ページ |
| `css/style.css` | 見た目（色、文字の大きさ、配置） |
| `js/check.js` | 確認ページのボタンと表示の動き |
| `js/meter.js` | レベルメーター（音の大きさの棒） |
| `js/settings.js` | 設定の保存と読み出し（タブレットのブラウザの中だけに保存） |
| `js/audio/capture.js` | マイクやUSB入力から音を取り込む |
| `js/audio/pcm-worklet.js` | 取り込んだ音を16kHz・モノラル・16bitに変換する |
| `js/audio/pcm.js` | 音データの連結、音量の計算、WAV形式への変換 |
| `js/audio/recordings.js` | 比較用の録音をタブレットの中に保存する |
| `js/audio/replay.js` | 保存した録音を、マイクの代わりの入力として流す |
| `.claude/launch.json` | Claude Codeがパソコンで表示確認をするための設定（アプリ本体には無関係） |

## パソコンで開いて確かめる

マイクは `https://` か `localhost` のページでしか使えません。ファイルをダブルクリックして開いても動かないので、このフォルダで次を実行し、Chromeで `http://localhost:8765/` を開きます。

```
python -m http.server 8765 --bind 127.0.0.1
```

## 守っていること

- APIキーは、ファイルにもリポジトリ（GitHub上の保管場所）にも書かない。設定画面で入力し、タブレットのブラウザの中だけに保存する。
- テレビの音声は保存しない。例外は、利用者が自分で操作して録る比較用の短い録音だけで、これもタブレットの中にとどめる。
